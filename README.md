# 🧠 NeuroGym — тренажёр мелкой моторики для детей с РАС на основе распознавания жестов

Десктопное приложение на Pygame для развития мелкой моторики у детей с расстройствами аутистического спектра (РАС). Приложение распознаёт движения руки через веб-камеру с помощью **MediaPipe Hand Landmarker**, преобразует координаты пальца в экранные действия и предлагает **5 интерактивных упражнений** с тремя уровнями сложности, системой достижений и минималистичным дизайном, адаптированным для сенсорных особенностей детей с РАС.

> **Проектная работа** для открытой городской научно-практической конференции «Инженеры будущего»

## 📌 О проекте

Существующие приложения для развития моторики либо требуют специализированного оборудования, либо не учитывают сенсорные особенности детей с РАС — перегружая интерфейс яркими анимациями, сложной навигацией и непредсказуемыми звуками. В результате дети не могут заниматься самостоятельно, а родители вынуждены постоянно контролировать процесс.

Данный проект решает эту проблему: приложение использует **обычную веб-камеру** для отслеживания движений указательного пальца, предлагает **минималистичный, предсказуемый интерфейс** с мягкой цветовой гаммой и **адаптирует сложность упражнений** под возможности ребёнка.

### Ключевые особенности

- 🖐️ **Управление жестами** — распознавание движений руки через веб-камеру (MediaPipe Hand Landmarker) с адаптивным 1€-фильтром для плавности курсора
- 🖱️ **Альтернативное управление мышью** — автоматическое переключение при отсутствии камеры
- 🎯 **5 упражнений** — «Следопыт», «Траектория», «Сортировка», «Запоминание последовательности», «Ловкие пальчики»
- 📊 **3 уровня сложности** — «Лёгкий», «Средний», «Сложный» с индивидуальными параметрами для каждого упражнения
- 🏆 **Система достижений** — звёзды, значки и коллекционные предметы с сдержанной анимацией
- 🌍 **Локализация** — русский и английский языки интерфейса
- 🎨 **Адаптированный дизайн** — мягкие пастельные цвета, крупные элементы (≥64×64 px), минимум анимаций для снижения сенсорной нагрузки
- 💾 **Автосохранение прогресса** — результаты, достижения и статистика сохраняются в JSON-файл

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/<ваш-username>/neuro_gym.git
cd neuro_gym
```

### 2. Установка Python

- **Windows**: скачайте установщик с [python.org](https://www.python.org/downloads/), отметьте «Add Python to PATH»
- **macOS**: `brew install python` или установщик с [python.org](https://www.python.org/downloads/)
- **Linux (Ubuntu/Debian)**:

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip libgl1 libglib2.0-0
```

### 3. Создание виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate          # macOS / Linux
# .\.venv\Scripts\Activate.ps1     # Windows (PowerShell)
```

### 4. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Это установит все необходимые библиотеки:

| Библиотека | Назначение |
|------------|-----------|
| `pygame==2.5.2` | Игровой фреймворк: окно, рендеринг, ввод, звук |
| `opencv-python>=4.10` | Захват видеопотока с веб-камеры |
| `mediapipe>=0.10.9` | Распознавание ключевых точек руки (Hand Landmarker) |

### 5. (Опционально) Проверка установки

```bash
python test_imports.py
```

### 6. Запуск приложения

```bash
python run.py
# или
python -m neuro_gym
```

Приложение откроется в окне **1280×720** с названием «NeuroGym».

## 🎮 Как пользоваться

1. **Запустите приложение** — откроется экран загрузки с логотипом
2. **Выберите сложность** — в главном меню переключите уровень: Лёгкий / Средний / Сложный
3. **Выберите упражнение** — перейдите в раздел «Упражнения» и выберите одно из пяти
4. **Прочитайте инструкцию** — перед первым запуском упражнения отображается краткая инструкция
5. **Выполняйте упражнение** — управляйте курсором с помощью указательного пальца перед камерой или мышью
6. **Изучите результаты** — после завершения (60 сек) отображаются звёзды, очки и статистика
7. **Отслеживайте прогресс** — раздел «Достижения» показывает разблокированные награды

### Упражнения

| Упражнение | Описание | Механика |
|-----------|----------|----------|
| **🔍 Следопыт** | Развитие координации и внимания | Следите за движущимся объектом, удерживая палец в зоне допуска |
| **✏️ Траектория** | Развитие точности движений | Проведите пальцем по нарисованному пути от начала до конца |
| **📦 Сортировка** | Категоризация и точность | Перетаскивайте объекты в правильные контейнеры (захват щипком) |
| **🧩 Последовательность** | Развитие памяти | Запомните и повторите порядок подсвеченных объектов |
| **⚡ Ловкие пальчики** | Скорость реакции | Касайтесь появляющихся объектов до их исчезновения |

### Управление

| Действие | Камера (жесты) | Мышь |
|---------|----------------|------|
| Перемещение курсора | Движение указательного пальца | Движение мыши |
| Клик / выбор | Удержание пальца на месте (0.8 сек) | Клик левой кнопкой |
| Захват объекта | Щипок (указательный + большой палец) | Клик и удержание |
| Перетаскивание | Движение при активном щипке | Перемещение с зажатой кнопкой |
| Назад | Быстрое движение пальца вниз | Кнопка «Назад» |

## 🔧 Как это работает

### Система распознавания жестов

```
Захват кадра с веб-камеры (30+ FPS)
       ↓
MediaPipe Hand Landmarker → 21 ключевая точка руки
       ↓
Извлечение координат кончика указательного пальца (точка 8)
и кончика большого пальца (точка 4)
       ↓
Адаптивный 1€-фильтр (One Euro Filter)
  → Убирает дрожание в покое
  → Не добавляет задержки при быстром движении
       ↓
Преобразование координат камеры → координаты экрана (1280×720)
       ↓
Интерпретация жестов:
  • Удержание позиции → Клик (dwell-клик)
  • Щипок (расстояние thumb–index < 0.40) → Захват
  • Движение при щипке → Перетаскивание
  • Быстрое вертикальное движение (> 500 px/сек) → Свайп
```

### Формула 1€-фильтра

$$
\hat{x}_i = \alpha \cdot x_i + (1 - \alpha) \cdot \hat{x}_{i-1}
$$

$$
\alpha = \frac{1}{1 + \frac{\tau}{T_e}}, \quad \tau = \frac{1}{2\pi f_c}
$$

где $f_c = f_{c_{\min}} + \beta \cdot |\dot{x}_i|$ — адаптивная частота среза, зависящая от скорости движения руки. При медленном движении фильтр сильно сглаживает (убирает тремор), при быстром — пропускает сигнал без задержки.

     └───────┘                     └─────────┘

- **game.py** — главный цикл: обработка событий, обновление состояния, рендеринг (60 FPS)
- **hand_tracker.py** — захват видео в отдельном потоке, распознавание через MediaPipe Tasks API, сглаживание 1€-фильтром, распознавание жестов (щипок, свайп, dwell-клик)
- **screen_manager.py** — стек экранов с жизненным циклом (on_enter / on_exit), ленивая загрузка через registry
- **input_handler.py** — унифицированный интерфейс ввода: абстрагирует камеру и мышь
- **progress_manager.py** — автосохранение прогресса в JSON после каждого упражнения
- **config.py** — единый файл конфигурации: размеры окна, цвета, пороги жестов, параметры упражнений

## 📋 Требования

- **Python** 3.10+
- **ОС**: Windows 10/11, macOS 10.15+, Linux
- **Веб-камера**: 720p, 30 FPS (опционально — можно играть мышью)

- **Зависимости**: Pygame 2.5, OpenCV 4.10+, MediaPipe 0.10.9+
